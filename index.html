Learn Git by Doing

This is a demo repository for students to practice the Fork, Branch, and Pull Request workflow.

1

Fork & Clone

Click the 'Fork' button on GitHub, then clone your copy to your local machine using VS Code.

2

Create a Branch

Run git checkout -b your-name to create a new branch before making any changes.

3

Push & PR

Add your info to the list below, push to your fork, and open a Pull Request!

💻 Terminal Step-by-Step

1. Initialize and set up remotes

# Clone your fork (replace with YOUR username)
git clone https://github.com/YOUR_USERNAME/SDK_Test.git

# Enter the directory
cd SDK_Test

# Add the original repo as 'upstream' to stay updated
git remote add upstream https://github.com/Master-Mind-007/SDK_Test.git

2. Create a feature branch

# Create and switch to a new branch
git checkout -b feature/add-my-name

3. Save and Push changes

# Stage your changes
git add .

# Create a commit message
git commit -m "Add [Your Name] to contributor list"

# Push to YOUR fork (origin)
git push -u origin feature/add-my-name

Final Step:

Go to your GitHub profile, open the repository, and click the green "Compare & Pull Request" button!
